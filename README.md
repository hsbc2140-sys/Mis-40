# Harrison 40 · Grandes éxitos

Invitación interactiva a los 40 de Harrison, en HTML, CSS y JavaScript puros.

## Abrirla
- Doble clic en `index.html`, o
- En VS Code, clic derecho en `index.html` → "Open with Live Server" (extensión Live Server).

## Editar los textos
Casi todo lo que se lee (datos de la fiesta, videos del televisor, audios, juegos, respuestas del chat) está en `js/contenido.js`.

## Publicarla
Es un sitio estático: se puede subir tal cual a GitHub Pages, Netlify o Vercel y compartir el link.
- Sube también el archivo `.nojekyll` de la raíz (está vacío): sin él, GitHub Pages ignora los archivos que empiezan por `_`.
- Si agregas imágenes, videos o sonidos, nómbralos en minúsculas, sin espacios, tildes ni símbolos (ej. `mi-foto.png`).
  El servidor distingue mayúsculas: `Foto.png` y `foto.png` son archivos distintos.
